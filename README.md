
# OpenBoard

OpenBoard is an open-source Kanban task management
application built with React and Vite.

It provides a lightweight interface for organizing
tasks and tracking their progress.

## Live Demo

https://dataman-py.github.io/openboard/

## Current Features

- Three-column Kanban board
- Create new tasks
- Delete existing tasks
- Assign task priorities
- Move tasks between workflow stages
- Store tasks in browser local storage
- Responsive user interface
- Automated unit tests
- GitHub Actions CI/CD

## Technology Stack

- React 19
- JavaScript
- Vite
- CSS
- Node.js built-in test runner
- GitHub Actions
- GitHub Pages

## Getting Started

Requirements: Node.js 22+

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Run automated tests:

```bash
npm test
```

Build for production:

```bash
npm run build
```

## Project Status

OpenBoard is currently an early-stage MVP.

The core Kanban interface and basic task management
features have been implemented.

Future development will focus on backend services,
database storage, task filtering, drag-and-drop
interactions, and collaborative features.

## Known Limitations

- Tasks are stored locally in each browser.
- Data is not synchronized across devices.
- User authentication is not implemented.
- Drag-and-drop is not yet supported.
- Advanced task filtering is planned.
